# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and assume good intent.
- Critique code and ideas, not people.
- No harassment, discrimination, sexualised content or personal attacks, in any project space.
- Don't publish anyone's private information without their permission.

## Reporting

Report unacceptable behaviour privately through a [GitHub security advisory](https://github.com/Dillan-03/verbose-octo-carnival/security/advisories/new) or by contacting the maintainer through their GitHub profile. Reports are handled confidentially.

## Enforcement

The maintainer may remove comments, issues or contributions that break this code, and may block people who repeatedly or seriously break it.
